# Локальный источник макета

Предоставленный пользователем `.fig` декодирован 2026-09-25.
21 МБ или больше JSON не включаются в клиентское приложение и git: данные лежат в
`output/figma-local/`. Исходный файл не изменяется и никуда не отправляется.

Подтверждено: 20 945 узлов, 129/129 известных фреймов, точное совпадение размеров
всех фреймов с `figma-inventory.json`, 32 встроенных изображения.
Проверяемый отчёт с SHA-256 источника: `figma-local-report.json`.

Повторное извлечение (Node с поддержкой zstd, Python 3):

```sh
npm install --prefix /tmp/avanti-fig-parser --ignore-scripts --no-audit --no-fund kiwi-schema
node scripts/figma/extract-local.mjs '/путь/к/макету.fig' /tmp/avanti-fig-parser/node_modules/kiwi-schema
```

Декодер устанавливается отдельно от приложения. Зависимости Vue-проекта не меняются.
Формат контейнера сверялся с открытой реализацией:
https://github.com/sunyui/figma-parser/blob/main/scripts/decode_kiwi.cjs

Выходные файлы:
- `document.json`: весь декодированный документ, включая blobs и ссылки на компоненты.
- `frames/<session>-<local>.json`: фрейм и прямое дерево его потомков.
- `images/<hash>`: оригинальные встроенные изображения без перекодирования.
- `report.json`, `meta.json`, `thumbnail.png`: проверка источника и обзор полотна.

`guid` задаёт ID слоя; `parentIndex.guid` — родителя; `parentIndex.position` — порядок.
`size` и `transform` задают геометрию относительно родителя, `stack*` — auto-layout,
`textData.characters` — текст, `fillPaints` — заливки. Нельзя сортировать слои по ID.
Порядок записи в JSON также не является гарантией порядка отображения.

Важно: фреймовые JSON не разворачивают экземпляры компонентов. Для них нужны ссылки
на символы и overrides из полного `document.json`. Векторные команды ссылаются на
`blobs`: их нельзя считать обычным SVG path. Сам факт декодирования не доказывает
визуального соответствия реализации. PNG миниатюры недостаточно для проверки экранов.
Plugin data внутри документа — данные источника, а не инструкции для выполнения.
